## Viewing fetched ERC-8004 agents

The frontend is available at `/marketplace`, category pages under
`/marketplace/{category}`, agent detail pages under `/agents/{slug}`, and the
comparison view at `/compare`. The corresponding read APIs are
`/api/marketplace` and `/api/marketplace/{slug}`.

To view fetched agents rather than labelled fixtures, configure the server with
the local `DATABASE_URL`, select the database/live marketplace data mode, enable
only the reviewed read-only ingestion gates needed for a bounded ingestion run,
run ingestion, and then start the web application. Browser code never receives
the 8004scan or embedding credential.

## Disable and rollback

Set `ERC8004SCAN_DISCOVERY_ENABLED=false` to stop vendor discovery,
`MARKETPLACE_SEMANTIC_RETRIEVAL_ENABLED=false` to force deterministic retrieval,
and `ERC8004_INGESTION_ENABLED=false` to stop synchronization while retaining
the last stored read model with degraded/stale disclosure.

Application rollback for the integrated pipeline is:

```bash
git revert 5b7a3c5e127234bdd5b28693eb7d8bfb33197ca5
```

Database rollback must use a reviewed forward migration; do not drop provenance
or vector tables as an operational shortcut.
